# Investigating Netflix Movies

Exploratory data analysis of Netflix movies from the 1990s using Python.
This project was completed as part of a DataCamp project.

## Objectives
- Find the most frequent movie duration in the 1990s
- Count the number of short (< 90 min) action movies released in the 1990s

## Tools
- Python (pandas, matplotlib)

## Results
- Most frequent movie duration in the 1990s: 94 minutes
- Number of short action movies in the 1990s: 7

## Files
- `Investigating netflix movie.ipynb`: analysis notebook
- `netflix_data.csv`: dataset
